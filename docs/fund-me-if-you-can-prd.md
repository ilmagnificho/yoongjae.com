# Fund Me If You Can - MVP PRD
## 실패하면 사기, 성공하면 비전

---

## 한 줄 요약
실리콘밸리의 가장 논란적인 AI 스타트업의 실화를 모티브로 한 풍자 텍스트 RPG. 창업자(Roi Kim) 또는 VC(Byron Park) 시점을 선택해 플레이. "정직과 허슬의 경계는 어디인가?"를 플레이어가 직접 결정한다.

## 포지셔닝
- **기존 VC Simulator와의 관계**: 독립 스핀오프. 크로스 프로모션은 하되 스토리/세계관은 별개
- **기존 게임과의 차이**: VC Simulator는 "한국 스타트업 생태계의 보편적 경험" 풍자 → 이 게임은 "실제 사건 기반 실리콘밸리 드라마"의 양면적 체험
- **디스클레이머**: "이 게임은 픽션이며, 실제 인물/기업/사건과 무관합니다" 문구 필수 삽입 (타이틀 화면 하단)

## 게임 구조

### 전체 플로우
```
[타이틀: Fund Me If You Can] → [역할 선택: Founder/VC] → [5개 챕터] → [엔딩 + 결과 카드]
```

- 챕터당 이벤트 2-3개 = 총 10-15개 이벤트
- 이벤트당 선택지 2-4개
- 플레이타임: 7-12분 (기존보다 약간 길게 - 스토리 몰입 필요)
- 엔딩: 루트별 5개씩 (총 10개)

## 스탯 시스템

### Founder 스탯 (Roi Kim) - 3개
| 스탯 | 아이콘 | 초기값 | 의미 |
|------|--------|--------|------|
| 하이프 (Hype) | 🔥 | 30 | 시장의 관심도/화제성. 높을수록 투자자가 찾아옴. 바이럴 선택 시 급등하지만 부작용 있음 |
| 신뢰도 (Credibility) | 🎯 | 70 | 업계/투자자/미디어로부터의 신뢰. 0 = 업계 퇴출 게임오버. 거짓말/과장할수록 하락 |
| 프로덕트 (Product) | ⚙️ | 20 | 실제 제품 완성도. 낮으면 DD에서 탈락, 리브랜딩 필요 |

**특수 메커니즘**: 하이프와 신뢰도는 **역상관 관계**. 대부분의 바이럴 선택은 하이프↑ + 신뢰도↓. 이 균형을 어떻게 관리하느냐가 게임의 핵심.

### VC 스탯 (Byron Park) - 3개
| 스탯 | 아이콘 | 초기값 | 의미 |
|------|--------|--------|------|
| 확신 (Conviction) | 💎 | 50 | 이 딜에 대한 투자 확신. 높아야 투심위 통과 |
| 평판 (Reputation) | 📊 | 70 | 업계/파트너/LP로부터의 평판. 0 = 커리어 종료 |
| 실사력 (Due Diligence) | 🔍 | 50 | 딜의 진짜 모습을 파악하는 능력. 높으면 red flag 발견 확률 증가 |

**특수 메커니즘**: 확신과 실사력이 **긴장 관계**. DD를 깊이 할수록 red flag이 보이고 확신이 흔들림. DD를 대충 하면 확신은 유지되지만 나중에 폭탄.

## 기술 구현

### 코드 구조 (권장)
```
fund-me-if-you-can/
├── index.html              # 엔트리포인트
├── css/
│   └── style.css           # 전체 스타일 + 픽셀아트 렌더링
├── js/
│   ├── engine.js           # 게임 엔진 (기존 VC Simulator 엔진 재활용 가능)
│   ├── founder.js          # Founder 루트 시나리오 데이터
│   ├── vc.js               # VC 루트 시나리오 데이터
│   ├── endings.js          # 엔딩 판정 로직
│   ├── ui.js               # UI 렌더링 + 대화 시스템
│   ├── sprites.js          # 캐릭터 스프라이트 데이터 (픽셀 배열)
│   ├── backgrounds.js      # 배경 픽셀아트 데이터
│   ├── audio.js            # 8bit 효과음 생성 (Web Audio API)
│   └── share.js            # 결과 카드 + SNS 공유
├── og-image.png            # OG 메타 이미지
└── README.md
```

### 픽셀아트 구현 방식
- **캐릭터 스프라이트**: JavaScript 배열로 픽셀 데이터 정의 → Canvas에 렌더링
- **배경**: CSS gradient + Canvas 조합으로 픽셀 배경 생성
- **스케일링**: `image-rendering: pixelated` (CSS) + Canvas scale로 선명한 확대
- **애니메이션**: requestAnimationFrame 기반 간단한 프레임 전환 (눈 깜빡임, 말풍선 등)
- **외부 에셋 없이 순수 코드로 생성**: 로딩 속도 최적화, 의존성 최소화

### 8bit 오디오 구현
- **Web Audio API** 사용 (라이브러리 불필요)
- OscillatorNode로 8bit 사운드 합성
- 효과음 5-6종만 (클릭, 스탯업, 스탯다운, 챕터전환, 엔딩)
- 사용자 설정으로 음소거 가능

### 기존 VC Simulator 코드 재활용
- engine.js의 상태 관리, 턴 진행, flags 시스템은 거의 그대로 사용 가능
- 스탯 이름과 초기값만 변경
- 시나리오 데이터 포맷 동일
- UI 레이어만 픽셀아트 버전으로 교체

### 다국어 지원
- 시나리오 데이터에 `ko` / `en` 키로 텍스트 분리
- 타이틀 화면에서 언어 선택 또는 브라우저 언어 자동 감지
- 결과 카드도 선택된 언어로 생성

- 개발: vc-vs-founder repo 또는 별도 repo
- 프로덕션: yoongjae.com/tools/fund-me/ (또는 별도 도메인)
